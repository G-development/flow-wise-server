🔐 Authentication & Users

User management and authentication endpoints

  • POST /users/register PUBLIC
    Register a new user account
  • GET /users/profile BEARER
    Get current user profile information
  • POST /users/profile/photo BEARER
    Upload and update user avatar
  • POST /auth/forgot-password PUBLIC
    Request a password reset email; answers 502 when the email cannot be sent
  • POST /auth/verify-reset-token PUBLIC
    Check that a reset token is still valid and return its email; 401 otherwise
  • POST /auth/reset-password PUBLIC
    Set a new password using a valid token

💰 Transactions

Complete CRUD operations for financial transactions

  • GET /transaction/all BEARER
    Get all transactions with optional date filters
  • GET /transaction/:id BEARER
    Get a single transaction of the authenticated user
  • POST /transaction BEARER
    Create a new transaction
  • PUT /transaction/:id BEARER
    Update an existing transaction
  • DELETE /transaction/:id BEARER
    Delete a transaction

📈 Income & Expenses

Specialized endpoints for income and expense data

  • GET /income/all BEARER
    Get all income transactions
  • GET /expense/all BEARER
    Get all expense transactions

🏷️ Categories & Wallets

Manage transaction categories and payment methods

  • GET /category BEARER
    Get all transaction categories
  • GET /category/active BEARER
    Get only active categories
  • GET /category/:id BEARER
    Get a single category
  • POST /category BEARER
    Create a category (name, type "I"/"E")
  • PUT /category/:id BEARER
    Update a category (name, type, active)
  • DELETE /category/:id BEARER
    Delete a category; 409 CATEGORY_IN_USE when transactions or budgets reference it
  • GET /wallet BEARER
    Get all user wallets, with the balance derived from transactions
  • POST /wallet BEARER
    Create a wallet; 409 past the three-wallet limit (database invariant)
  • PUT /wallet/:id BEARER
    Update name, is_default or opening_balance_cents; the final balance is never writable
  • DELETE /wallet/:id BEARER
    Delete a wallet; 409 WALLET_IN_USE when transactions or budgets reference it

📥 CSV Import

Bulk import of transactions from a CSV document

  • POST /import/csv BEARER
    Import rows from a CSV body ({ csv }); required columns Type, Amount, Date, Category, Description

🏦 Bank Integration

GoCardless Open Banking (PSD2) and the sandbox fallback

  • GET /bank/config BEARER
    Setup status of the integration: mock or live mode, and what is missing
  • GET /bank/institutions BEARER
    Banks supported by the configured provider
  • GET /bank/authorize?bank=<id> BEARER
    Authorization URL that starts the PSD2 consent flow; 503 when the integration is not configured
  • GET /bank/mock-auth?state=<...> PUBLIC
    Sandbox consent page; answers 403 unless the mock is explicitly enabled
  • GET /bank/callback PUBLIC
    OAuth redirect target: verifies the state, saves the connection and runs the first sync
  • GET /bank/connections BEARER
    Bank connections of the authenticated user, with the last sync time
  • GET /bank/status?bank=<id> BEARER
    Connection state for one bank
  • POST /bank/sync?bank=<id> BEARER
    Sync the movements of one connected bank
  • GET /bank/transactions?bank=&startDate=&endDate= BEARER
    Synced movements; envelope { transactions, count, truncated, total }
  • POST /bank/import BEARER
    Move selected bank movements into Flow Wise ({ transactionIds, walletId, categoryId, defaultType? })
  • POST /bank/disconnect?bank=<id> BEARER
    Disconnect a bank and drop its stored tokens
  • GET /bank/scheduler/status SECRET
    State of the periodic sync scheduler; 503 without BANK_SCHEDULER_SECRET
  • POST /bank/scheduler/sync-now SECRET
    Force a global sync for every connected user

📊 Dashboard

🤖 AI Analytics

One-shot analysis of the user's expenses

  • POST /agents/analytics BEARER
    Analyse expenses for a period ({ question, startDate, endDate }); the answer declares how many movements were covered. 503/504/502 on provider errors, no conversation memory
