🚀 Flow-Wise API

Welcome to the Flow-Wise API documentation. Here you'll find all available endpoints to integrate with your financial data.

API Status: Online

🔐 Authentication & Users

User management and authentication endpoints

  • POST /users/register
    Register a new user account
  • GET /users/profile
    Get current user profile information
  • POST /users/profile/photo
    Upload and update user avatar

💰 Transactions

Complete CRUD operations for financial transactions

  • GET /transaction
    Get all transactions with optional date filters
  • POST /transaction
    Create a new transaction
  • PUT /transaction/:id
    Update an existing transaction
  • DELETE /transaction/:id
    Delete a transaction

📈 Income & Expenses

Specialized endpoints for income and expense data

  • GET /income/all
    Get all income transactions
  • GET /expense/all
    Get all expense transactions

🏷️ Categories & Wallets

Manage transaction categories and payment methods

  • GET /category
    Get all transaction categories
  • GET /category/active
    Get only active categories
  • GET /wallet
    Get all user wallets

📊 Dashboard

Dashboard layout and configuration

  • GET /dashboard-layout
    Get current dashboard layout
  • PUT /dashboard-layout
    Update dashboard layout configuration

🔧 Utilities

Utility endpoints for testing and monitoring

  • GET /hello
    Simple hello world endpoint for testing
  • GET /healthz
    Health check endpoint for monitoring
